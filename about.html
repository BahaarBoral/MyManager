🌱 Why MyManager Exists

🎓 For College Students

College life throws money, freedom, screens and responsibility all at once. Most students aren't taught how to manage this shift.

💸 Time & Money Awareness

MyManager helps students see where your time and money actually go, especially impulsive spending and endless scrolling.

🌿 Change Without Pressure

This isn't about guilt or perfection. It's about gentle awareness and better habits over time.


📌 Syllabus Concepts Used

Concept Where Used
for / while loops money.js, time.js, analytics.js, tasks.js, dashboard.js
onchange Time page (hours input), Analytics (date filter), Pomodoro (music)
onclick All buttons — Add Expense, Save Log, Add Task, etc.
onmouseover / onmouseout Dashboard cards, Analytics cards (JS hover effects)
Radio buttons Time Sink — Peak usage time
Checkboxes Time Sink — Activity selection, Tasks — completion toggle
Dropdowns (select) Money Leak — category/reason, Analytics — date range
Form validation money.js, time.js — required fields, range checks
External JS files money.js, time.js, analytics.js, dashboard.js, tasks.js, pomodoro.js
DOM manipulation All JS files — getElementById, createElement, etc.
Semantic HTML header, nav, main, section, article, footer — all pages
CSS box model Margins, padding, borders throughout style.css
Canvas API analytics.js (pie chart, bar chart), time.js (bar chart)
localStorage All data persistence — expenses, time logs, tasks, pomodoro, profile

🎬 How It Works

MyManager uses localStorage to save your data directly in the browser. No server needed — your data stays private and local. Just open the HTML files and start tracking your habits!
